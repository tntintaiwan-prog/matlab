# 每個資料夾是一堂完整課程

- `001-kmeans`：目前的 K-means 成果，內容頁保留 MATLAB 與 Python，互動頁使用 JavaScript。
- `_template`：可複製的完整範本，包含正弦波的內容、兩種程式碼與互動頁。底線開頭的資料夾不會發布。

複製 `_template` 為 `002-topic`，修改 `lesson.json`、`content.md`、`matlab.m`、`python.py`、`interactive.html`，提交到 GitHub 即可。

若使用 Word，移除 `content.md`，改放 `report.docx`；課程設定與互動程式仍需保留。請勿直接把 Word 放在本資料夾根目錄。

詳細操作見根目錄 `README.md` 與 `GITHUB_PAGES.md`。
